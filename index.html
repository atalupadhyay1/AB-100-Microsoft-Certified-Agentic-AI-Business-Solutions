Human Analogy Giving the model an up-to-date open-book reference library at runtime. Sending the model to specialized trade school to learn a new style, jargon, or compact output format.
Data Freshness Real-time / Near-real-time (instant updates when documents or CRM rows change). Static snapshot as of training date (requires retraining when facts change).
Security & ACL Trimming Enforces per-user ACLs via On-Behalf-Of (OBO) authentication & search filters. No per-user row security—anything baked into model weights can be surfaced to any caller!
When to Choose on AB-100 Enterprise policies, product catalogs, live CRM/ERP records, citations required. Distilling a domain task into a fast, low-cost Small Language Model (SLM) or strict proprietary syntax.
Protocol Direction Analogy & How It Works AB-100 Exam Trigger Phrase
Model Context Protocol (MCP) Vertical (Agent → Tool / Resource) Universal USB-C port for AI tools. Expose tools/resources once on an MCP server (`x-ms-agentic-protocol: mcp-streamable-1.0`); Copilot Studio & Foundry dynamically discover new tools at runtime. "Share standardized tools across multiple agents with automatic runtime schema discovery."
Agent2Agent (A2A) Protocol Horizontal (Agent ↔ Peer Agent) Peer collaboration protocol. Agents publish an Agent Card describing capabilities and delegate conversational tasks across Copilot Studio, Microsoft Foundry, and third-party clouds. "Delegate a sub-task from an Orchestrator Agent in Copilot Studio to a Specialist Agent in Microsoft Foundry."
