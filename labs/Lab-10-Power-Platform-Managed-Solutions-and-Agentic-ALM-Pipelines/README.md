## 1. Lab Scenario & Business Objective (Humanized Context)

**Fabrikam, Inc.** has built an end-to-end AI Customer Sentiment & Concierge solution in its **Development** environment consisting of:
1. A custom **Microsoft Dataverse Table** (`Customer Reviews`),
2. A **Power Apps Canvas App** (`Fabrikam Store Manager App`),
3. An **AI Builder Sentiment Analysis & Prompt Flow** (`Sentiment Routing Agent Flow`),
4. A **Microsoft Copilot Studio Agent** (`Fabrikam Support Concierge`),
5. **Environment Variables** (for the SharePoint grounding URL and Microsoft Foundry endpoint), and
6. **Connection References** (for Dataverse, Office 365 Outlook, and ServiceNow).

You need to convert this **Unmanaged Solution** in Development into a locked, production-ready **Managed Solution**, validate it with **Power Platform Solution Checker**, and automate its promotion across **Development -> UAT -> Production** using **Power Platform CLI (`pac`)** and **GitHub Actions** (`deployment-settings.json`).

## 2. Step-by-Step Hands-On Instructions

### Part A: Portal Walkthrough — Bundling Components & Exporting as a Managed Solution

1. **Create the Custom Publisher and Unmanaged Solution in Development:**
   - Sign in to `https://make.powerapps.com` -> Select your **Development** environment (`Fabrikam-Dev`).
   - Select **Solutions -> + New solution**:
     - **Display name:** `Fabrikam Agentic Customer Operations`
     - **Name:** `FabrikamAgenticCustomerOperations`
     - **Publisher:** Create a custom publisher (`Fabrikam AI CoE`, prefix `fab`).
2. **Add All Solution Components & Required Dependencies:**
   - Inside the solution, select **Add existing**:
     - **Table:** `Customer Review (fab_customerreview)` (Include table metadata + forms/views).
     - **App -> Canvas app:** `Fabrikam Store Manager App`.
     - **Agent (Copilot):** `Fabrikam Support Concierge` (automatically adds its Topics and Knowledge pointers).
     - **Automation -> Cloud flow / Agent flow:** `Sentiment Routing Agent Flow`.
     - **More -> Environment variable:** `fab_SharePointPolicySiteUrl` and `fab_FoundryModelEndpoint`. *(Important: Select each Environment Variable -> `...` -> **Advanced -> Remove from this solution** for the **Current Value** before exporting so Dev URLs don't overwrite Prod URLs!)*
     - **More -> Connection reference:** `fab_DataverseConnRef` and `fab_ServiceNowConnRef`.
3. **Run Solution Checker (Pre-Deployment Static Analysis Gate):**
   - On the Solutions command bar, select **Solution checker -> Run**.
   - Wait for the analysis to complete and verify there are **0 Critical / High** issues (such as hardcoded URLs, missing connection references, or deprecated APIs).
4. **Publish All Customizations & Export as Managed Solution:**
   - Select **Publish all customizations**.
   - Select **Export -> Next -> Export as: Managed** (for UAT/Production import) and also export a copy as **Unmanaged** (for unpacking into Git source control).
5. **Import into Target Environment (UAT / Production) with Environment Settings:**
   - Switch the environment picker in `make.powerapps.com` to **`Fabrikam-UAT`** (or use **Power Platform Pipelines**).
   - Select **Solutions -> Import solution** -> Upload `FabrikamAgenticCustomerOperations_1_0_0_1_managed.zip`.
   - When prompted during import:
     - Bind the **Connection References** to UAT Service Principal connections, and
     - Enter the **UAT SharePoint Site URL** and **UAT Foundry Endpoint** into the **Environment Variables** prompts!

### Part B: Pro-Code CLI & Automated CI/CD Pipeline Walkthrough

Review the three complete automation files in `solution/`:
1. **[`solution/pac-alm-commands.sh`](./solution/pac-alm-commands.sh):** Exact **Power Platform CLI (`pac`)** commands to export, unpack to human-readable source files (including `.mcs.yml` agent topics) for Git commits, run Solution Checker, pack as a Managed Solution, and import with `deployment-settings.json`.
